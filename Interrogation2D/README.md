# So‘roq — 2D prototype

A portrait-oriented, mobile-friendly 2D interrogation scene in Uzbek.

## Run
Open `index.html` in a modern browser. No build tools or external assets are required.

## Current prototype
- Canvas-rendered room, table, chair and suspect illustration
- Animated breathing and blinking
- Four Uzbek interaction buttons with dialogue responses
- Small synthesized interaction tones and optional vibration
- Responsive portrait layout

## Important
This is an early 2D visual prototype. The suspect is currently drawn with procedural canvas shapes; it is not yet a photorealistic character or a finished Android APK. High-resolution character artwork, richer frame-by-frame animation, recorded Uzbek voice acting, sound design, story progression and Android packaging remain future work.
