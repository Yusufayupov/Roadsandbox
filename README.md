# Допрос: камера 04

Android-игра от первого лица, в которой игрок ведёт допрос подозреваемой в комнате для допросов.

## Возможности
- Ландшафтный полноэкранный режим.
- Вид от первого лица с камерой, столом и подозреваемой.
- Действия и кнопки управления расположены по бокам экрана.
- Счётчик действий и меняющиеся реплики персонажа.
- Ненатуралистичные визуальные отметки состояния персонажа.
- Кнопка «Вернуть образ» сбрасывает состояние к исходному.

## Сборка APK
Открой вкладку **Actions** в GitHub и скачай артефакт **InterrogationGame-debug** после успешной сборки.

Локальная сборка: `gradle assembleDebug`.
