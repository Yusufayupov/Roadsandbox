# So‘roq — 3D Android prototipi

Unity 2022.3 LTS uchun haqiqiy real-time 3D sahna. Xona, stol, yorug‘lik, stul va gumonlanuvchi Unity 3D mesh-primitivlaridan ishga tushganda yaratiladi. Kamera birinchi shaxsdan, UI esa vertikal telefon ekraniga mos.

## Ishga tushirish
1. Unity Hub → Add → tanlang: `Unity3D`.
2. Unity Editor 2022.3 LTS bilan oching.
3. Assets/Scripts/Interrogation3D.cs skriptini bo‘sh sahnadagi GameObject’ga biriktiring.
4. Play bosing.

## Android
Unity Hub ichida Android Build Support, Android SDK & NDK Tools va OpenJDK o‘rnating. Build Settings → Android → Switch Platform → Build.
Hozirgi repo manba loyihani beradi; tayyor APK hali build qilinmagan. Fotorealistik inson modeli, motion-capture animatsiyalar va professional audio keyingi resurs bosqichida qo‘shiladi.
