# Interrogation 3D — Godot 4

This is the new 3D branch of the Android interrogation game. It replaces the earlier 2D Canvas prototype with a real-time 3D scene.

## Current 3D build
- Portrait mobile layout and first-person camera.
- 3D interrogation room with furniture, lighting and shadows.
- A procedural 3D suspect character with separate face, hair, eyes, clothing and hands.
- Idle breathing, head motion, blinking and action reactions.
- Uzbek Latin dialogue, evidence action, pressure/trust meters and touch UI.

## Important
The character is currently assembled from procedural 3D meshes. It is a playable 3D prototype, not a photorealistic scanned human model or a finished commercial game. A high-quality rigged human model, facial blendshapes, recorded Uzbek voice acting and authored animation clips are still separate production tasks.
